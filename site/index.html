DRS XML Generator

This web app takes in XLS files from the Digital Library and creates an XML file ready for submitting to Crossref to register or update DOI information. Upload the .xls file and fill in the conference information. If there are errors generating the XML, you can fix them before uploading.

Check this Google Doc for help using this tool: DRS XML Generator: how to use it
